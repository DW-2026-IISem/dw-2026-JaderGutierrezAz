# HuellaVet · Frontend

Frontend Angular 22 (signals, PrimeNG 22 con Aura y Tailwind CSS 4) de HuellaVet,
historia clínica veterinaria. Consume el backend Express en `http://localhost:4000/api`.

- `npm start` sirve la aplicación en http://localhost:4200
- `npm run build` genera `dist/`
- `npm test -- --watch=false` ejecuta las pruebas

La evidencia del recorrido vive en `docs/`.
